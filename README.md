# ERP & POS Fuente de Soda - Operación Lean Carabayllo

Sistema integral de Punto de Venta (POS), Pantalla de Cocina (KDS) y Gestión de Recursos Empresariales (ERP) diseñado para fuentes de soda, juguerías y restaurantes.

## Módulos Principales

- **Punto de Venta (POS):** Toma de pedidos rápidos, selección de mesas, barra o delivery, y cálculo de cobros.
- **Cocina (KDS):** Kitchen Display System para recepción y despacho de comandas en tiempo real.
- **Recetas y Costos:** Escandallo de productos, cálculo de costos unitarios y márgenes de ganancia.
- **Inventario e Insumos:** Catálogo de materias primas con control de stock mínimo.
- **Kardex:** Trazabilidad completa de ingresos, salidas y mermas de insumos.
- **Compras y Proveedores:** Gestión de órdenes de compra, directorio de proveedores y registro detallado de facturas/boletas.
- **Mermas y Producción:** Registro de desperdicios operativos y órdenes de producción.
- **Combos y Promociones:** Armado de paquetes con lógica de precios promocionales.
- **Historial de Ventas:** Registro de comprobantes emitidos, anulaciones y reportes.
- **Configuración:** Parámetros de la empresa (RUC, razón social), configuración de mesas y preferencias del sistema.

## Tecnologías

- **Framework:** React 19 + TypeScript
- **Estilos:** Tailwind CSS
- **Herramienta de construcción:** Vite
- **Iconos:** Lucide React

## Scripts Disponibles

- `npm run dev`: Inicia el servidor de desarrollo local.
- `npm run build`: Compila el proyecto para producción en TypeScript y Vite.
- `npm run preview`: Previsualiza la versión compilada de producción.
